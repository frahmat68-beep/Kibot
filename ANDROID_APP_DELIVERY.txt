                        QUICK START GUIDE
================================================================================

1. BUILD THE APP
   $ cd apps/android
   $ ./gradlew assembleDebug

2. INSTALL ON DEVICE
   $ ./gradlew installDebug

3. CONFIGURE SERVER
   - Open app
   - echo SettingsTap 
   - Enter server IP:port
   - Tap Save

4. VIEW LOGS
   $ adb logcat | grep "KiBot"
